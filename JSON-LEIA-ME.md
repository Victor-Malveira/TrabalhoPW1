# Integração JSON no estilo do agenda

Um arquivo JavaScript por modelo (empresa, candidato e avaliação). Cada operação tem sua função, seus próprios campos e fetch com JSON.stringify.
O rota.php recebe JSON com json_decode dentro do switch e responde com json_encode.
Os formulários usam botões type="button" e onclick; a busca e as avaliações recebem JSON.
Execute no XAMPP com Apache e MySQL e banco importado.
